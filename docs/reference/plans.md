# Plans

Prices: [sprott.ai/pricing](https://sprott.ai/pricing).

| Feature | Local | Pro | Team |
|---|:--:|:--:|:--:|
| The broker, phantoms and `sprott run` | ✅ | ✅ | ✅ |
| Every service in the catalog, custom connections | ✅ | ✅ | ✅ |
| Agents | unlimited | unlimited | unlimited |
| Passkey approvals and policy | ✅ | ✅ | ✅ |
| Activity, with every call recorded on your machine | ✅ | ✅ | ✅ |
| Agent access per vault | ✅ | ✅ | ✅ |
| Activity in the console | last 7 days | last 90 days | last 90 days |
| [Overview](../activity.md#the-overview) of every agent | ✅ | ✅ | ✅ |
| Machines | one | several, synced | several, synced |
| Vaults | one personal vault | several | several |
| More passkeys to unlock and approve | | ✅ | ✅ |
| Per-agent, per-connection access | | ✅ | ✅ |
| [Shared vaults](../team.md), members, roles and invites | | | ✅ |
| Team activity, attributed to person, agent and machine | | | ✅ |

- **Pro** has a 14-day trial, no card needed. You can start it when you
  create your first vault.
- **Team** is billed per seat. Seats count people; agents don't take seats.
  Creating a shared vault starts a 30-day team trial, no card needed. Every
  seat includes everything in Pro.
- **Enterprise** adds SSO, a self-hosted control plane and compliance
  support. [Contact us](https://sprott.ai/pricing).
