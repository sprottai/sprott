# Plans

Prices: [sprott.ai/pricing](https://sprott.ai/pricing).

| | Personal | Pro | Team |
|---|:--:|:--:|:--:|
| The broker, phantoms and `sprott run` | ✅ | ✅ | ✅ |
| Every service in the catalog, custom connections | ✅ | ✅ | ✅ |
| Passkey approvals and policy | ✅ | ✅ | ✅ |
| Which agents get in, per-agent and per-connection access | ✅ | ✅ | ✅ |
| [Overview](../activity.md#the-overview) of every agent | ✅ | ✅ | ✅ |
| Activity, with every call recorded on your machine | ✅ | ✅ | ✅ |
| Activity in the console | last 7 days | last 30 days | last 90 days on shared vaults |
| Private vaults | 2 | unlimited | unlimited |
| Machines | 3 | 10 | 10 per seat |
| Passkeys | 3 | 10 | 10 per seat |
| Agents | 3 | 50 | 50 per seat |
| [Shared vaults](../team.md), members, roles and admin approvals | | | ✅ |
| Team activity, attributed to person, agent and machine | | | ✅ |

- Limits count per account. At a limit you can't add another until you
  remove one; nothing you already have is removed.
- An agent is an identity: subagents and jobs an agent starts count as that
  agent ([Subagents](../agents.md#subagents)).
- Activity older than the console's window is deleted from Sprott's
  servers. Each machine keeps the full history of its own calls.
- Until billing opens, Pro is waived: every account gets Pro's limits.
- **Team** is billed per seat. Seats count people; agents don't take seats.
  A new team gets a 30-day trial, no card needed. Every seat includes
  everything in Pro.
- **Enterprise** adds SSO, a self-hosted control plane and compliance
  support. [Contact us](https://sprott.ai/pricing).
